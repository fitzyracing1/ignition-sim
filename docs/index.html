⚠ Safety — simulator only

This project is a software model only. It does not control engines, vehicles, ECUs, ignition coils, spark plugs, or any hardware. Do not wire it to a real ignition system or use its outputs as calibration for a street or race vehicle. Misusing ignition timing on a real engine can destroy the engine and create fire / injury hazards.

Product story

What it models

Given an engine operating point (rpm, normalized load), it returns demo dwell time, spark advance (degrees BTDC), and a fixed spark duration. Battery voltage is assumed constant. There is no knock sensor, no IAT/CLT compensation, and no proprietary OEM map import.

IN

Inputs

rpm — engine speed (rev/min).
load — normalized load in [0, 1].

OUT

Outputs

dwellMs — coil charge time.
advanceDeg — spark advance BTDC.
sparkDurationMs — fixed demo spark event.

≈

Formulas

Piecewise-linear RPM advance table, load correction that retards under heavy load, and RPM-scaled dwell clamps. Educational approximations only.

Library

API (brief)

Install from the repo, then call computeIgnition. Optional second argument overrides demo defaults (still not an OEM tune).

import { computeIgnition, DEFAULT_CONFIG } from "fakegreen01";

const { dwellMs, advanceDeg, sparkDurationMs } = computeIgnition({
  rpm: 2500,
  load: 0.4,
});

const custom = computeIgnition(
  { rpm: 4000, load: 0.7 },
  { ...DEFAULT_CONFIG, baseAdvanceDeg: 12 },
);

Develop

How to run tests

Clone the repo, install with Node.js 22+, then lint / test / build.

git clone https://github.com/fitzyracing1/ignition-sim.git
cd ignition-sim
npm install
npm test          # Vitest
npm run lint      # tsc --noEmit
npm run build     # → dist/
npm run fakegreen:name # next random fakegreen codename
npm run fakegreen      # optional: scan for fake-green patterns

CI on main and pull requests runs install → lint → test → build, plus fakegreen on PRs. GitHub Pages publishes from main / docs/.
